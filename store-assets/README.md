# Store Assets

Images for the Chrome Web Store listing. **You create these** — they are not generated by the build.

## Required

| Asset | Size | Notes |
|-------|------|-------|
| **Extension icon** | 128×128 PNG | Already in `public/icons/icon-128.png` — upload in Dashboard |
| **Screenshot** | At least 1 | See sizes below |

## Screenshot sizes

Chrome accepts:

- **1280×800** (recommended)
- **640×400** (minimum)

Up to **5** screenshots. Use PNG or JPEG.

## Suggested screenshots

Capture these from a real session after `npm run build` + load `dist/`:

1. **Popup** — “Take Screenshot” with Visible Area / Full Page buttons
2. **Editor overview** — toolbar + screenshot with annotations
3. **Annotation detail** — arrows, text, highlight example
4. **Keyboard shortcuts sheet** — press `?` in editor
5. **Dark mode** (optional) — editor in dark theme

## Tips

- Use a clean website in the background (not personal data)
- Crop to 1280×800 in any image editor, or resize browser window before capture
- Avoid blurry upscales — capture at native resolution

## File naming (optional)

```
01-popup.png
02-editor.png
03-annotations.png
04-shortcuts.png
05-dark-mode.png
```

Place files in this folder before uploading to the Developer Dashboard.
