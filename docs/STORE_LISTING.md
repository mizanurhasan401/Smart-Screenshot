## Detailed description

### English

```
Chrome Screenshot Pro helps you capture and annotate web page screenshots quickly — entirely on your device.

CAPTURE
• Visible Area — screenshot what you see right now
• Full Page — capture entire scrollable pages (regular http/https websites)

EDIT
• Crop, text, arrows, rectangles, circles, highlights, and blur
• Move, select, undo/redo
• Zoom, pan, and keyboard shortcuts

EXPORT
• Copy to clipboard
• Download as PNG, JPG, or WEBP

PRIVACY FIRST
• No account required
• No cloud upload
• No analytics or tracking
• All processing stays in your browser

HOW TO USE
1. Click the extension icon
2. Choose Visible Area or Full Page
3. Annotate in the editor
4. Copy or download your image

Note: Full page capture works on standard website tabs only (not chrome:// pages or the Chrome Web Store).
```

## Permission justifications (Privacy practices form)

### activeTab

**EN:** Required to capture the visible portion of the active browser tab when the user clicks the extension.

**BN:** ইউজার এক্সটেনশন ক্লিক করলে সক্রিয় ট্যাবের দৃশ্যমান অংশ ক্যাপচার করতে লাগে।

### tabs

**EN:** Used to read the active tab’s URL and title for labeling captures and to check if full-page capture is supported on that tab.

**BN:** ক্যাপচার লেবেল ও full-page সাপোর্ট চেক করতে ট্যাবের URL/title পড়তে লাগে।

### scripting

**EN:** When the user chooses full-page capture, injects a short script into the active tab they selected to scroll and measure page height for stitching. Runs only on user request on that tab only. No data is transmitted to external servers.

**BN:** ইউজার Full Page বেছে নিলে শুধু সেই ট্যাবে স্ক্রল ও উচ্চতা মাপতে স্ক্রিপ্ট চালায়; বাইরের সার্ভারে ডেটা যায় না।
